# MySocial

A clean social-media-style web app starter built with plain HTML, CSS and JavaScript.

## Current features
- Responsive social feed
- Stories row
- Create posts
- Likes
- Comments
- Search
- Follow buttons
- Dark mode
- Browser local storage

## Run
Open `index.html` in a browser, or open the repository in VS Code and use Live Server.
